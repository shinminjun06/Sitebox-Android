# SiteBox 3.0.6 검증판

압축을 풀고 SiteBox-3.0.6.apk를 설치하세요. 기존 3.0.1~3.0.5 검증판과 동일한 키로 서명했습니다.

- 배경 테마는 테마 1 공부방만 남기고 나머지 11개 테마와 이미지 및 기존 교실 대체 배경을 제거했습니다.
- 축소된 책장의 위치·크기와 오른쪽 옆면 원근, 나무 채도·대비 및 접지 그림자를 조정했습니다.
- 삭제된 테마의 기기 설정과 클라우드 백업은 공부방으로 전환합니다. 책·메모·카테고리와 책장·책 재질은 보존합니다.

단위 테스트 36개, Java 기하 및 리소스 검사, debug/release lint와 APK 서명을 확인했습니다.
동봉된 화면은 앱의 네이티브 렌더링 미리보기입니다. 실제 휴대폰 조작과 Google 로그인은 이 환경에서 검증하지 못했습니다.
APK는 동봉된 소스 변경으로 클라우드에서 빌드·서명했으며 Actions에서는 다시 빌드하지 않고 전달합니다. 앱의 소스 버전 표시는 빌드 당시 기준 커밋과 dirty 표시를 포함합니다.
