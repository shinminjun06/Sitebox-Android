# SiteBox 3.0.7 검증판

ZIP을 풀고 SiteBox-3.0.7.apk를 설치하세요. 기존 3.0.1~3.0.6 검증판과 동일한 검증용 키로 서명했습니다.

- 참고사진에 맞춰 축소 책장을 정면에 가까운 얕은 원근과 차분한 나무 톤으로 조정했습니다.
- 책장 위에 작은 화분·액자·머그컵 소품을 추가했습니다. 소품은 책장과 함께 낮·밤 및 조명 전환에 반응하며 확대 시 사라집니다.
- 실제 저장된 책을 표시하는 방식과 책장 열기 동작, 테마 1만 제공하는 구성은 유지했습니다.
- 좁은 옆면에 나뭇결이 과하게 눌려 보이지 않도록 텍스처 샘플링 범위를 조정했습니다.

단위 테스트 37개, Java 기하·이미지 검사, debug/release lint와 APK 서명을 확인했습니다.
동봉된 미리보기의 책들은 테스트용 예시 데이터입니다. 앱 설치 시 예시 책을 추가하지 않습니다.
미리보기는 앱의 네이티브 렌더링 결과이며 실제 휴대폰 조작과 Google 로그인은 이 환경에서 검증하지 못했습니다.
APK는 이 배포 소스 변경으로 클라우드에서 빌드·서명했습니다. Actions는 완성된 APK를 재빌드 없이 전달하며, 앱의 소스 버전 표시는 빌드 당시 기준 커밋과 dirty 표시를 포함합니다.
