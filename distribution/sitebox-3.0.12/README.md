# SiteBox 3.0.12 검증판

ZIP을 풀고 SiteBox-3.0.12.apk를 설치하세요. 이전 3.0.x 검증판과 같은 키로 서명했습니다.

- 책장 그림의 투명한 여백 때문에 정면과 옆판 사이로 배경이 보이던 틈을 닫았습니다.
- 옆판·윗판을 실제 목재 가장자리까지 연결하고 불투명한 목재 바탕을 먼저 그립니다. 좁은 텍스처 영역만 투영해 패널을 채웁니다.
- 세로 책장 밑변의 기울기를 약 2.85도에서 1.9도로 완만하게 조정했습니다.
- 책장 배치, 낮·밤 자동 전환, 스탠드 조명과 실제 책 데이터는 유지합니다.

single-book-day/night.png는 테스트 책 한 권을 넣은 591×1206 앱 렌더링입니다. cabinet-panel.png는 배경 없이 그린 책장으로 옆판의 막힌 상태를 확인할 수 있습니다. 테스트 책 데이터는 앱에 포함되지 않습니다.
단위 테스트 43개, 패널 투명도 검사, 목표 사진의 모서리·기울기 검사, 기존 원근·이미지 검사, debug/release lint와 APK 서명을 확인했습니다. 휴대폰 실기기는 이 환경에서 확인하지 못했습니다.
APK는 동봉된 소스로 클라우드에서 빌드·서명했습니다. Actions는 완성 APK를 전달합니다.
