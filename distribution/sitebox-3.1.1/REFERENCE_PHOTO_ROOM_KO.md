# SiteBox 3.1.1 — 원본 사진 배경과 실제 책장

사용자가 제공한 목표 사진을 **수정 없이** `themes/rooms/student/room_reference.jpg`에 복사했습니다. SHA-256은 `275373adaff1581fa1d089ce74f21ff1dc9540ccf9a9eb5bd45f7bc19d0f6e18`입니다. 방의 책상·벽·모서리·창문·침대·전경 소품은 모두 이 원본에서 그립니다. 별도 제작한 책상/전경·책장 입체 모형·합성 접지 그림자를 방 화면에 얹지 않습니다.

사용자가 선택한 대로 **책장 영역만 실제 저장된 책으로 바뀝니다.** 원본 책장 사진의 내부를 비운 3×3 사진(`reference_cabinet.webp`)에서 책장 사각형만 사용합니다. 이 이미지의 나머지 방과 책상은 렌더링하지 않습니다. 기존 `BookshelfView`의 실제 책 View를 그 9칸에 맞춰 그리므로 추가·삭제·순서·검색·페이지·동기화 변경이 바로 반영됩니다. 장식용 가짜 책 데이터는 추가하지 않습니다.

## 렌더링과 좌표

- 기본 사진: 원본 JPEG 720×1280. 기기 크기에 맞춰 한 장의 사진으로 확대·이동합니다. 왼쪽 벽과 책장을 자르지 않도록 세로 화면의 가로 크롭을 오른쪽에 배분합니다.
- 책장 핫스팟/목표 프레임: 원본 정규 좌표 TL `(0,0.170)`, TR `(0.216,0.235)`, BR `(0.216,0.598)`, BL `(0,0.670)`.
- 빈 책장 사진: 941×1672, RGB WebP. 소스 프레임 TL `(0,0.170)`, TR `(0.216,0.235)`, BR `(0.216,0.598)`, BL `(0,0.670)`. 네 점의 행렬로 실제 프레임 좌표에 맞추고, 원본 책장 사각형 안에서만 클립합니다.
- 전면 식물: 책장 사진 왼쪽의 녹색 잎만 작은 알파 마스크로 한 번 캐시해 책 앞에 다시 그립니다. 별도 책상이나 가구를 생성하지 않습니다.
- 실제 책: 네 점 행렬과 칸별 보정 좌표를 공유합니다. 정면으로 편 좌표에서 열은 `(0.015–0.160, 0.195–0.558, 0.600–0.966)`, 행 바닥은 `(0.310, 0.590, 0.925)`이며 열별 ±0.006 높이 보정을 적용합니다. 사진에서 일부 잘린 가장 왼쪽 칸을 임의로 늘리지 않습니다. 칸당 기존 7권 및 페이지 규칙을 유지합니다. 확대 중에는 칸 위치를 기존 정면 편집 좌표로 연속 보간합니다.
- 접근·복귀: 기존 550ms 단일 타임라인과 반전·핀치·Android Back을 유지합니다. 편집 화면에서 실제 3×3 책 관리 기능을 사용합니다. 원본 방 사진과 별도로 만든 책상을 서로 다른 속도로 움직이지 않습니다.
- 조명: 같은 사진에 지역 시간·구름의 색감 보정과 국소 스탠드 조명을 적용합니다. 책장 사진과 실제 책도 같은 색감 계산을 사용합니다. 사진 속 물체나 책상 모양을 교체하지 않습니다.
- 날씨: 실제 Open-Meteo/도시·캐시·오프라인 기능을 유지합니다. 구름량은 원본 사진의 색감·밝기에 반영하고, 창문에는 비·눈 효과만 그리며, 원본 풍경을 다른 동영상으로 교체하지 않습니다. 이전 구름 타원·사각형 매트는 사진 모드에서 그리지 않습니다. 사진 모드에서는 영상 디코더를 시작하지 않습니다.

## 적용 이미지와 추가 개선 에셋

| 파일 | 크기 / 용도 |
| --- | --- |
| `room_reference.jpg` | 720×1280, 업로드 원본. 방·책상·벽·창문·전경 전체 |
| `reference_cabinet.webp` | 941×1672, RGB. 등록된 책장 사각형만 사용; 나머지 방 픽셀은 미사용 |
| `cabinet_front.webp` | 1100×1430, 투명 프레임. 기존 정면 3×3 편집 화면 |
| 기존 `themes/books/` | 기존 3개 책 테마의 책등과 실제 제목 View 재사용 |

위 에셋은 모두 적용되어 있습니다. 책장 사진과 원본 사진은 한 번 디코딩해 기기 해상도/저메모리 설정에 맞춰 캐시하며, 식물 가림 마스크도 처음 한 번만 계산합니다. 확대 중에는 실제 책 View를 행렬로 그려 책등·제목을 매 프레임 큰 비트맵으로 다시 만들지 않습니다.

물리적인 야간 그림자까지 바꾸려면 같은 카메라·가구 위치·720×1280 이상의 별도 야간 사진이 필요합니다. 가로 전용 구도가 필요하면 동일 배치의 16:9 사진과 해당 사진에서 측정한 책장 네 점을 추가해야 합니다. 현재 가로 화면은 세로 원본과 여백을 사용하며, 제공되지 않은 사진이 있다고 표시하지 않습니다.

## 데이터와 빌드

Java/Android 기본 View·Canvas·Matrix를 유지합니다. 계정/Drive 자동 동기화와 SharedPreferences 책·메모·즐겨찾기·순서·테마 형식은 변경하지 않습니다. 같은 검증용 릴리스 키, `com.sitebox.app`, versionCode 27, versionName `3.1.1-photo`를 사용합니다.

원본 파일 동일성, 책장 바깥의 책상·벽 픽셀 보존, 책 데이터가 방/편집 양쪽에 반영되는지, 9칸 좌표·페이지·상태 보존·애니메이션·실제 명패 글자와 기존 계정/동기화 회귀 검사를 실행합니다. 최종 빌드·Android 15·서명 APK 설치 결과는 배포 자료에 기록합니다.
