# SiteBox 3.0.5 검증판

ZIP을 풀고 SiteBox-3.0.5.apk를 설치하세요.
기존 3.0.1~3.0.4 검증판과 동일한 검증용 키로 서명했습니다.
운영 서명키로 설치된 앱에는 업데이트할 수 없습니다.

이 작업은 클라우드에서 이미 빌드·서명한 APK를 Actions 다운로드로 전달합니다.
APK에는 아직 기준 커밋에 반영되지 않은 작업 중 변경 사항이 포함되어 있습니다.
이 배포 브랜치의 앱 소스로 APK를 다시 빌드한 것이 아닙니다.
테스트 33개와 서명 검증은 로컬 빌드 시 통과했습니다.
실제 휴대폰 Google 로그인·설치는 이 환경에서 확인하지 못했습니다.
