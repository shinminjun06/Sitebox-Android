# SiteBox 3.0.10 검증판

ZIP을 풀고 SiteBox-3.0.10.apk를 설치하세요. 이전 3.0.x 검증판과 같은 키로 서명했습니다.

- 테마 1 축소 책장의 깊이 방향을 방의 벽 선으로 다시 계산하고 위치·크기를 조정했습니다.
- 투명 여백을 제외한 실제 발끝에 접지 그림자를 붙였습니다.
- 노출된 옆면에 뒤쪽 다리를 추가하고, 앞·뒤 발과 책장 밑의 바닥 그림자를 함께 그립니다.
- 실제 저장한 책, 확대 화면과 계정·동기화 기능을 유지합니다.

single-book-day/night.png는 테스트 책 한 권을 넣은 591×1206 앱 렌더링입니다. empty-day/night는 빈 책장, portrait-day/night는 테스트 책 27권을 넣은 화면입니다. 테스트 데이터는 앱에 포함되지 않습니다.
단위 테스트 41개, 원근·이미지 검사, debug/release lint와 APK 서명을 확인했습니다. 휴대폰 실기기 조작은 이 환경에서 확인하지 못했습니다.
APK는 동봉된 소스로 클라우드에서 빌드·서명했습니다. Actions는 완성 APK를 전달합니다.
