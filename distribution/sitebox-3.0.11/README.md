# SiteBox 3.0.11 검증판

ZIP을 풀고 SiteBox-3.0.11.apk를 설치하세요. 이전 3.0.x 검증판과 같은 키로 서명했습니다.

- 사용자가 지정한 목표 사진을 기준으로 세로 책장을 창문 왼쪽에 배치하고, 앞면 각도·크기와 소품 비율을 맞췄습니다.
- 스탠드를 켠 밤에도 벽·커튼·바닥에 푸른 달빛과 나뭇잎 그림자를 유지합니다. 따뜻한 빛은 전구와 책상 주변에 남깁니다.
- 책장과 소품의 야간 색을 달빛에 맞게 조정했습니다.
- 기존 낮·밤 자동 전환, 조명 스위치, 실제 책 데이터와 확대 화면을 유지합니다.

single-book-night/day.png는 테스트 책 한 권을 넣은 591×1206 앱 렌더링입니다. portrait-night/day는 테스트 책 27권을 넣은 예시이며 테스트 데이터는 앱에 포함되지 않습니다.
기존 원본 이미지와 앱의 조명 합성으로 구현했습니다. 이미지 재편집 서비스는 HTTP 400 오류로 사용할 수 없었으며 목표 사진과 픽셀 단위로 동일한 새 배경을 생성한 것은 아닙니다.
단위 테스트 42개, 목표 사진의 책장 모서리 비교, 원근·이미지 검사, debug/release lint와 APK 서명을 확인했습니다. 휴대폰 실기기는 이 환경에서 확인하지 못했습니다.
APK는 동봉된 소스로 클라우드에서 빌드·서명했습니다. Actions는 완성 APK를 전달합니다.
