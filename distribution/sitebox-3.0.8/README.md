# SiteBox 3.0.8 검증판

ZIP을 풀고 SiteBox-3.0.8.apk를 설치하세요. 3.0.1~3.0.7 검증판과 동일한 키로 서명했습니다.

- 정면을 직사각형으로 고정하던 원근 오류를 수정했습니다. 배경에서 측정한 소실점에 따라 정면·윗면·옆면을 함께 투영합니다.
- 세로·가로 배경은 각각 천장 몰딩과 걸레받이 선을 기준으로 보정합니다. 낮은 책장의 윗면도 보이도록 눈높이를 맞췄습니다.
- 세로 책장이 벽 모서리를 넘어가지 않도록 위치·크기를 조정하고, 뒤쪽 발을 걸레받이 아래 바닥에 맞췄습니다.
- 양쪽 발의 서로 다른 바닥 높이에 맞춰 접지 그림자를 조정했습니다.
- 실제 저장한 책·메모, 소품과 조명 동작, 테마 1만 제공하는 구성은 유지합니다.

단위 테스트 37개, 배경선과 소실점·바닥 접지 검사, 576개 면 경계 검사, 이미지 검사, debug/release lint와 APK 서명을 확인했습니다.
삽화 배경의 원근은 측정선에 따른 근사 보정입니다. 미리보기는 테스트용 책을 넣은 앱의 네이티브 렌더링 결과이며 실제 휴대폰 조작은 이 환경에서 확인하지 못했습니다.
APK는 동봉된 소스 변경으로 클라우드에서 빌드·서명했습니다. Actions는 완성 APK를 전달하며 앱의 소스 버전 표시는 빌드 당시 기준 커밋과 dirty 표시를 포함합니다.
