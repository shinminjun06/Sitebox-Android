# SiteBox 3.0.13

ZIP을 풀고 SiteBox-3.0.13.apk를 설치하세요. 이전 3.0.x 검증판과 같은 키로 서명했습니다.

- 축소 책장의 정면 그림에 옆판을 덧붙이던 방식 대신, 선반 안쪽부터 기둥·옆판·윗판·다리까지 같은 입체 구조로 그립니다.
- 방의 벽선과 걸레받이로 원근을 맞추고, 책장의 바닥 접촉점에 그림자를 연결했습니다.
- 기존 목재 이미지의 질감을 각 판에 입히고, 실제 저장된 책만 해당 칸 안쪽에 표시합니다.
- 낮·밤 자동 전환, 조명 스위치, 책 데이터와 Google 계정 기능을 유지합니다.

single-book-day/night.png는 테스트 책 한 권을 넣은 591×1206 앱 렌더링입니다. cabinet-panel.png는 배경 없이 그린 책장입니다. 테스트 책 데이터는 APK에 포함되지 않습니다.
단위 테스트 43개, 독립적으로 측정한 방의 원근 검사, 내부 선반 깊이 검사, 패널 투명도·다리 접촉 검사, 기존 Java/이미지 검사, debug/release lint, APK 빌드와 서명을 확인했습니다. 실제 휴대폰의 동작과 Google 로그인은 이번 환경에서 검증하지 못했습니다.
APK는 동봉된 소스로 클라우드에서 빌드·서명했습니다. Actions는 완성 APK를 전달합니다.
