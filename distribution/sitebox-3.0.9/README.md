# SiteBox 3.0.9 검증판

ZIP을 풀고 SiteBox-3.0.9.apk를 설치하세요. 이전 3.0.x 검증판과 같은 키로 서명했습니다.

- 기본 원목 책장의 축소 모습을 참고사진에 가까운 단순한 목재 프레임으로 교체했습니다.
- 축소 상태에서 카테고리 명패를 숨기고, 실제 저장한 책만 새 선반 위치에 맞춰 표시합니다.
- 목재가 회녹색으로 보이던 색상 보정을 줄이고, 옆면의 색과 낮·밤 명암을 조정했습니다.
- 기존 확대 책장, 데이터, 테마 1의 배경·조명 전환과 보정된 원근 및 접지는 유지합니다.

미리보기 empty-day/night는 빈 책장, portrait-day/night는 테스트 책 27권을 넣은 네이티브 렌더링입니다. 테스트 데이터는 앱에 포함되지 않습니다.
단위 테스트 38개, 이미지·원근 검사, debug/release lint 및 APK 서명을 확인했습니다. 실제 휴대폰 조작은 이 환경에서 확인하지 못했습니다.
APK는 동봉된 소스로 클라우드에서 빌드·서명했습니다. Actions는 완성 APK를 전달합니다.
