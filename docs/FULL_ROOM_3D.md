# SiteBox 3.3 · 실제 3D 책과 방향성 조명

Java/Android View와 기존 책 JSON·계정·자동 동기화를 유지합니다. Android API24+/OpenGL ES3.0, Filament/gltfio1.69.0. 이번 변경에 추가 외부 콘솔 설정은 없습니다.

## 원본 모델과 좌표

사용자 제공 `SiteBox_FullRoom_3D_HQ_v4_fixed.glb`를 `models/student_room.glb`에 그대로 보존합니다. 2,657,484 bytes, 724 meshes, 25,076 triangles, SHA256 `e27c10b8333187cfe210dbb5513350ed3cea883f773a132216ca16ff293d9e02`. 루트의 Z-up → Y-up 변환은 `(x,y,z)→(x,z,-y)`입니다. 원본 책상·침대·왼쪽 벽·천장·커튼·창틀·책장 프레임을 사용합니다.

책장 전면 X=-2.25..-1.11, Y=-.05..2.15, Z=-.774m. 칸 선반 지지면은 위부터1.4385/.7485/.0585m입니다. 실제 책 밑면은 지지면+.5mm, 깊이는.26.. .335m이며 뒷판 앞에 들어갑니다. 원본 BOOK_SLOT_R1이 아래 행인 점을 반영해 기존 위→아래 카테고리를 유지합니다.

## 실제 3D 책과 입력

`SolidBookGeometry`는 각 실제 데이터의 책을 양쪽 하드커버·안쪽 종이 블록·페이지 단면·8분할 곡면 책등으로 만듭니다. 커버와 책등의 윗면·아랫면·뒷면을 닫아 옆에서 보아도 평면이 드러나지 않습니다. 책등 제목·즐겨찾기 그림은 기존 `BookArtworkView`에서 캐시하고 곡면 UV에 적용합니다. 책 전체가 실제 광원과 그림자를 받습니다. 드래그 중 원래 책은 커버·종이·책등이 함께 어두워지고 완료 후 돌아옵니다. 빈 칸에 가짜 장식 책을 추가하지 않습니다.

`RoomModelGeometry`와 `RoomCameraRig`가 모델, 실제 책, 네이티브 입력의 좌표를 공유합니다. 확대 완료 후 네이티브 View는 터치·접근성만 맡고 중복 그림은 생략합니다. 실제 데이터 추가·수정·삭제·메모·즐겨찾기·드래그, 3×3칸·칸당7권·페이지·검색을 유지합니다. 책장 터치로 접근, 핀치/Back으로 방에 복귀합니다. 길게 누르기는 책 이동이며 빈 공간 길게 누르기로 축소하지 않습니다. 550ms 감속 전환은 현재 진행도에서 반전됩니다.

## 실제 창 구멍과 창밖

원본 뒤 벽 `Wall_Back_029`는 창문 구멍이 없는 직사각형입니다. 해당 메시만 런타임에서 제외하고, X=-.9..1.85/Y=.97..2.67m의 창문 구멍을 둘러싼 네 개의 회벽 볼륨을 같은 위치에 만듭니다. 왼쪽 벽과 천장은 그대로 남고 그림자를 차폐합니다. 기존 평면 `Window_Neighborhood_Reference`는 숨깁니다. 원본 GLB 파일을 재작성하지 않습니다.

창밖에는 실제 깊이를 가진 일본식 주택16채, 기와 지붕·용마루·창살, 나무·지형·전선과 전봇대를 병합 메시로 배치합니다. 가까운 거대 구형 수관과 타원 구름은 제거했습니다. 하늘은 CC0 실제 촬영 파노라마 세 장(맑은 낮/흐린 낮/별이 있는 밤)을2048×1024로 한 번 로딩하여 동일한 구에 적용하고 투명도로 연속 혼합합니다. [출처·라이선스·변환·해시](THIRD_PARTY_SKY_ASSETS.md). 창밖 물체는 카메라에 따라 실제 시차를 보이며 실내 스탠드가 하늘 밝기를 바꾸지 않습니다.

밤의 흐림/비/눈에서도 구름 사진이 별밤을 가리고 직접 달빛을 줄입니다. 비는 유리 물방울/자국, 눈은 유리 가장자리와 지붕 재질로 표현합니다. 현재 빗방울·눈입자가 움직이는 시뮬레이션은 없습니다. 기존 Open-Meteo/도시 시간대를 사용하며 네트워크 단절 시 저장 상태/기기 시각으로 동작합니다. 날씨 변경은 책 데이터를 다시 로드하지 않습니다.

## 방향성 조명

햇빛 방향은 rear window→실내 바닥으로 들어오는 정규화 벡터(-.46,-(.62+.18×day),+.66)입니다. 햇빛 그림자맵2048px(저사양1024), 주변광은 하늘 SH로 제공하고 카메라를 따라가는 가짜 전면 광원은 두지 않습니다. 창틀·벽·책·가구가 실제 그림자를 만듭니다. Filament의 normalBias는 미터가 아니라 최대 샘플 오차의 배율이므로 공식 기본값1.0을 사용합니다(상수 오프셋은1mm). 작은 미터값으로 잘못 설정한 경우의 shadow acne를 피하도록 보정했습니다. 넓고 평평한 벽/천장에서 나타난 화면 공간 간접그림자 패턴을 피하기 위해 SSAO는 사용하지 않고 실제 그림자맵을 사용합니다. 낮 햇빛 최대85,650lux, 흐림에서 직접광을 줄입니다.

스탠드는 실제 갓 아래(-.36,1.30,-1.16)의850lm 스폿 조명이며22°/54° 원뿔, 하향 벡터(.12,-1,.22), 그림자맵1024px(저사양512)을 사용합니다. 광원 밝기와 전구 표면을 함께 끄고 켭니다. 카메라 접근은 광량을 바꾸지 않습니다. ISO는 낮200→밤1000으로 완만하게 보정하고 밤에도 책등이 읽히도록 하늘 간접광을 유지합니다. 누락된 glTF metallicFactor 기본값1은 나무·종이·직물에 맞게0으로 보정합니다.

## GPU 자원과 표시 동기화

정적인 방은 매번 디코딩하거나 계속 렌더링하지 않습니다. 카메라/책/날씨/레이아웃 변경 때 프레임을 제출하고 pause에서 정지합니다. 책의 메시·제목 텍스처는 데이터/레이아웃/드래그 표시 변경 때만 갱신합니다. 최대 긴 변2048px(저사양1024)의 캐시 두 장을 재사용합니다. GPU 업로드는 beginFrame 전에, 교체한 버퍼·텍스처 해제는 endFrame 뒤에 수행합니다. 비트맵 업로드 콜백 전에는 비트맵을 재사용하지 않습니다.

`RenderRevision`은 카메라·책·조명·재질 변경을 각각 새 버전으로 추적하고, 실제 SurfaceTexture 타임스탬프가 해당 버전의 완성된 프레임과 일치한 후 입력/캡처를 진행합니다. 이전 카메라와 같더라도 옛 책 데이터 프레임을 완료로 오인하지 않습니다. UI RenderThread의 콜백 시각 차이는16ms 타임스탬프 확인으로 처리하며 추가 GPU 렌더링은 하지 않습니다. 레이아웃 요청이 남아 있는 책장을 빈 책 메시로 굳히지 않습니다.

## 검증과 남은 범위

순수 Java/JUnit/Robolectric은 닫힌 책 볼륨·법선·UV·지지면·드래그 표시, 실제 벽 개구부·야외 깊이·기하량, 햇빛/스탠드/주변광과 프레임 버전, 기존 책/계정/동기화 회귀를 검사합니다. Actions Android15 swangle에서 실제 GPU 화면, 책 CRUD/드래그, 물리 제스처, 크기/회전,7가지 날씨, 생명주기와 자동 동기화 로직을 검사합니다. 최종 검사 결과와 설치 링크는 아래 및 배포 BUILD_INFO에 기록합니다.

물리 기기의60fps/발열/전력은 아직 측정하지 않았습니다. 실제 Google 계정 동의와 실계정 Drive 전송은 자동 검사의 범위 밖입니다. 기존 OAuth 패키지는 `com.sitebox.app`, 검증판 서명 SHA1 `CD:84:36:B7:75:DA:5A:45:9F:76:26:8F:D5:65:C6:E5:8E:1A:D1:9C`이며 [기존 콘솔 안내](GOOGLE_DRIVE_SETUP_KO.md)를 유지합니다. 비·눈 입자 애니메이션, 건물 내부/차량 이동, 고급 지구 조명 시뮬레이션은 구현하지 않았습니다.
