# Natural cabinet, 2.6-school

The miniature now uses a camera-based perspective cuboid. Each source room has a camera principal point and depth/distance ratio. Camera coordinates use the same source-image crop matrix as the background and the actual safe-area-clamped cabinet envelope. The rear rectangle scales toward that vanishing point, while the front remains parallel to the wall. A single uniform pixel scale fits the face union into the envelope, centers horizontal padding, and retains original front proportions with its feet at the envelope bottom. Only physically visible side and top faces draw. Rear uprights shorten, shared crown edges coincide, and front feet stay grounded.

Each finish loads a bounded, cached square wood surface, with cabinet bitmap fallback. The body ends at the plinth above the sprite feet. The drawable color filter avoids a full-size offscreen layer; zero projection clears the filter. Ground-shadow geometry uses explicit layout dimensions before the first miniature layout. A room-specific color matrix blends with the projection animation, adjusting the complete miniature including books without changing the expanded UI. Narrow foot contacts accompany a soft directed floor shadow. All animation timing, gestures, data and theme independence remain unchanged.

Pure JDK geometry tests cover all rooms, portrait/landscape/small windows, actual crop transforms, identity endpoints, floor contact, shared crown edges, bounds, visibility and rear height ratios. Native tests compare actual rendered matrices and accept legitimately hidden faces. Screenshot capture now requires a fresh pre-draw frame and checks settled collapsed visibility. Native device execution and visual calibration remain CI responsibilities.
