# SiteBox 3.1.0 학생 방 — 구현과 검증

## 코드와 호환성

Java 17, Android 기본 View/Canvas/Matrix, minSdk 24·targetSdk 35를 유지했습니다. Compose·게임 엔진·3D 모델 의존성을 추가하지 않았습니다. 기존 `MainActivity`의 3×3·칸당 7권·페이지·검색·추가·삭제·상세·메모·즐겨찾기·드래그 기능을 같은 `BookshelfView`에 연결합니다.

기존 SharedPreferences의 책·카테고리·순서·책장/책 테마 및 Google 계정·Drive 자동 동기화 형식을 유지합니다. 원격 데이터를 반영할 때 화면을 강제로 확대하거나 사진을 다시 캡처하지 않고 현재 방의 책 데이터만 갱신합니다. 예전 배경 ID는 책을 유지하며 테마 1 학생 방으로 연결합니다.

## 구현한 화면

- 제공된 학생 방 사진을 기준으로 창문·커튼·책상·의자·침대·소품 구도를 유지한 낮/밤 사진을 적용했습니다. 배경의 기존 책장은 제거했습니다.
- 창밖, 실내 마스크, 접지 그림자, 사진 책장+실제 책, 장식, 투명 전경 책상, 조명, 제스처를 나눴습니다. 창틀·커튼·식물·스탠드 윤곽은 실내 알파 마스크로 보존합니다.
- 같은 고해상도 책장 프레임과 실시간 책 View를 원근 행렬로 그립니다. 행렬의 역변환으로 9칸과 가구 실루엣을 판정합니다. 확대 끝에서는 실제 편집 View의 위치·크기에 맞춰 넘깁니다.
- 터치 접근, 두 손가락 오므리기, Android 뒤로 가기를 연결했습니다. 하나의 550ms 감속 타임라인으로 움직이며 도중 반전·반복 요청을 처리합니다.
- 창밖은 천천히, 전경은 더 크게 이동합니다. 화면 비율별 안전한 구도·이동 범위·창밖 여유 영역으로 레이어 틈을 방지합니다.
- 지역 시간·Open-Meteo의 기존 날씨/오프라인 상태, 조명 스위치, 낮/밤 전용 반사광·그림자, 동영상의 생명주기 제어를 유지했습니다. 효과 줄이기 옵션과 저메모리 기기 기본값을 추가했습니다.

좌표·파일 규격·캐시와 전체 레이어 표는 [에셋과 렌더링 명세](STUDENT_ROOM_ASSETS_AND_LAYERS.md)에 있습니다.

## 검증 범위와 추가 에셋

실제 Google 동의 화면·실계정 Drive 전송, 실물 휴대폰의 60fps·발열·GPU 메모리는 이번 자동 검사로 증명하지 않습니다. 계정/동기화 회귀 검사는 독립된 테스트 계정 상태와 저장소 대역을 사용합니다. 사진 전환 때문에 Google Cloud 설정을 새로 바꿀 필요는 없으며 기존 OAuth 설정은 [설정 문서](GOOGLE_DRIVE_SETUP_KO.md)를 따릅니다.

필수 방·창밖·전경·책장 이미지는 모두 적용했습니다. 추가 개선용으로는 다음 이미지가 유용합니다.

- 가로 전용 구성: 1920×1080 실내, 동일 등록의 낮/밤·전경·창문 알파. 현재는 세로 구도를 안전하게 유지하고 주변 색으로 채웁니다.
- 새벽/노을 사진: 기존과 같은 941×1672 등록 또는 전체 세트를 1080×1920으로 교체. 현재는 지역 시간으로 낮/밤 사진을 부드럽게 혼합합니다.
- 커튼·나뭇잎 움직임: 같은 창문 등록과 실내 가림을 유지하는 영상/알파 시퀀스. 제공한 480×480 무음 영상은 정지 사진 루프이며, 움직이는 구름·비·눈은 기본 Canvas 효과입니다.

자유롭게 회전하는 3D 방은 구현 범위에 포함하지 않습니다. 최종 APK·체크섬·서명·화면·빌드 로그는 배포 브랜치의 `distribution/sitebox-3.1.0/`에 함께 제공합니다.
