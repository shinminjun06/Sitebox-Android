# Full Room 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Replace the entire room presentation with the supplied GLB while keeping actual books and account data.
**Architecture:** Native Filament renderer behind existing Android Views. A shared camera rig projects model shelf openings into the live book layer and fits the editor to the same GLB frame.
**Tech Stack:** Java 17, Android Views, Filament/gltfio 1.69.0, glTF 2.0.
**Spec:** docs/superpowers/specs/2026-10-23-full-room-3d-design.md

## Global Constraints
- minSdk 24, targetSdk 35; preserve SharedPreferences and Google/Drive code.
- One supplied GLB, one model frame in room/editor, 3×3 cells, seven books per cell/page.
- 550ms reversible transition; only two-pointer contraction or Back retreats.
- Same verification signing key, package com.sitebox.app; no key material committed.

## Review Focus
- Portrait/landscape and keyboard resize must keep native controls aligned with model openings.
- Surface recreation/pause must not leak engines or render stale surfaces.
- Book long press must still drag; empty long press must not collapse/hide UI.
- Missing weather/network must preserve local books and usable room.
- R8 release must include native libraries and load the GLB on a real Android runtime.
