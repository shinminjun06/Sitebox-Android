# Google 계정 · 백업

설정 → Google 계정 · 백업에서 북마크, URL, 메모, 즐겨찾기, 순서, 9개 카테고리, 책장·책·배경 테마, 영상 설정을 수동 저장하고 복원할 수 있습니다. 자동 동기화 기능은 아닙니다.

## 지금 파일로 Google Drive에 저장하기

1. 휴대폰의 Google Drive 앱에 원하는 구글 계정으로 로그인합니다.
2. SiteBox 설정 → Google 계정 · 백업 → **파일로 저장 · Google Drive 선택 가능**을 누릅니다.
3. Android 파일 선택기에서 Google Drive, 계정, 폴더를 선택해 JSON 파일을 저장합니다.
4. 파일 선택기에 Drive가 없다면 Drive 앱 설치·로그인 상태를 확인합니다. 기기에 저장한 뒤 Drive 앱으로 업로드할 수도 있습니다.
5. **백업 파일 불러오기**에서 파일을 선택하고 북마크 개수를 확인한 뒤 **복원**을 누릅니다.

파일 제공자에 쓰기가 끝나면 저장 완료를 표시합니다. 실제 서버 업로드 완료 여부는 Drive 앱에서 확인합니다. 파일 선택기 방식은 아래 앱 OAuth 등록 없이 이용할 수 있으며, 앱에 구글 계정을 직접 연결하는 기능과 구분됩니다.

## 앱 안에서 직접 구글 계정 연결하기

Google Cloud 프로젝트 소유자가 아래 설정을 완료해야 실제 연결을 사용할 수 있습니다. 앱 코드는 공식 Google Identity Services AuthorizationClient를 사용합니다. 비밀번호나 클라이언트 시크릿을 앱에 넣지 않습니다.

1. Google Cloud Console에서 앱 소유자의 프로젝트를 선택하거나 만듭니다.
2. Google Drive API를 사용 설정합니다.
3. Google Auth Platform에서 앱 이름 SiteBox, 지원 이메일, 개발자 연락처, 대상 사용자와 테스트 사용자를 설정합니다. 테스트 상태라면 사용할 구글 계정을 테스트 사용자로 등록합니다.
4. **Android 유형 OAuth 클라이언트**를 등록합니다. 웹 클라이언트 시크릿은 필요하지 않습니다.

| 설치판 | Android 패키지 | 인증서 SHA-1 |
|---|---|---|
| 업데이트판 | com.sitebox.app | 66:06:89:A5:05:37:55:BD:FA:81:43:FB:26:F7:26:C4:9E:AD:9C:AF |
| 병렬 설치판 | com.sitebox.app.preview | 66:06:89:A5:05:37:55:BD:FA:81:43:FB:26:F7:26:C4:9E:AD:9C:AF |

인증서 SHA-256: `1D:47:37:08:3B:D4:FA:B5:CA:73:0F:53:52:E2:20:D3:5B:37:B7:CD:65:A1:07:1A:E5:AC:FC:8B:FE:03:90:C8`.
빌드 인증서가 바뀌거나 Play App Signing으로 배포하면 실제 설치된 APK의 인증서를 기준으로 다시 등록해야 합니다.

요청 범위는 `https://www.googleapis.com/auth/drive.appdata` 하나입니다. 일반 Drive 문서 전체에 접근하지 않고 앱 전용 숨김 폴더에 JSON 백업을 새 파일로 추가합니다. 직접 연결의 백업은 일반 Drive 폴더 목록에 나타나지 않습니다. 앱에서 **Drive 최근 백업 불러오기**로 복원합니다. 학교판과 병렬판을 같은 Cloud 프로젝트에 등록할 때는 프로젝트 설정과 앱 데이터 접근 동작을 실제 계정으로 확인해야 합니다.

## 저장과 복원 규칙

- 직접 Drive 백업은 이전 파일을 덮어쓰거나 지우지 않고 새 시각의 파일을 추가합니다.
- 내려받기만 하거나 복원 확인을 취소하면 현재 데이터를 바꾸지 않습니다.
- 최대 2MiB / 북마크 10,000개를 허용합니다. 손상된 형식, 위험한 URL, 잘못된 카테고리 등을 거부합니다.
- 복원 직전 현재 데이터를 앱 내부 `before-restore.json`에 원자적으로 보관한 뒤 설정을 한 번에 저장합니다. **복원 전 기기 사본 불러오기**로 되돌릴 수 있습니다. 앱 삭제 시 내부 사본도 삭제됩니다.
- 파일 읽기·쓰기와 Drive 통신은 작업 스레드에서 처리하며, 시간 제한·크기 제한을 둡니다.
- 계정·접근 토큰은 메모리에만 둡니다. 재실행 시 연결을 다시 확인합니다. 구글 동의 화면 중 회전하면 연결 확인부터 다시 진행하며 저장/복원 버튼을 다시 눌러야 할 수 있습니다.
- 연결 해제는 앱의 Drive 접근 권한을 해제합니다. 앱에는 백업 파일 삭제 기능이 없습니다. Google 계정에서 앱 데이터 자체를 삭제하면 백업이 사라질 수 있습니다.
- 기상 캐시·위치 설정·구글 인증 정보는 백업하지 않습니다.

## 검증 범위

CI에서 Android 문서 URI 저장·읽기, 손상 파일 거부, 복원 취소·확인, 데이터·설정·복구 사본 보존과 기존 앱 기능을 검사합니다. 테스트 전용 문서 제공자로 검사하며 실제 Google 계정 동의 및 Google Drive 서버 전송은 등록된 Cloud 프로젝트/계정 없이 성공했다고 주장하지 않습니다.
